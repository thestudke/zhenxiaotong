# 发热与感染健康科普

## 适用症状

发热、发烧、畏寒、乏力、咳嗽、咳痰、咽痛等常见感染相关表现，可优先咨询呼吸科或内科，由医生结合检查判断病因。

## 发热观察

发热需要结合体温、精神状态、饮食饮水、尿量、皮疹、咳嗽、腹泻和持续时间综合判断。儿童、老人、孕妇、免疫功能低下者或有基础病人群出现发热时，应更谨慎。

## 高危信号

高烧不退、意识异常、抽搐、呼吸困难、持续呕吐、明显脱水、皮肤紫绀、精神反应差等情况，需要及时线下就医。

## 日常处理

保持补液和休息，记录体温变化，不建议自行叠加多种药物。是否使用退热药、抗感染药物应结合医生评估。

## 咳嗽咳痰

咳嗽伴黄痰、脓痰常提示气道或肺部感染可能，需要结合体温、气促、胸痛和持续时间判断。不建议自行使用抗生素，是否需要抗感染治疗应由医生根据检查决定。

## 居家观察与就医时机

居家期间应保证饮水、清淡饮食和充分休息，并记录体温曲线。体温持续超过 38.5℃ 达 3 天以上、咳嗽加重、出现气促或胸痛时，应及时前往呼吸科门诊就诊。
