# 失眠与睡眠障碍健康科普

## 常见表现

入睡困难、夜间易醒、早醒、睡后不解乏、白天困倦或注意力下降，都可能属于睡眠障碍。短期失眠常与压力、作息紊乱、情绪波动、咖啡因或酒精摄入有关。

## 睡眠卫生建议

固定起床时间比固定入睡时间更重要；睡前 1 小时减少手机和强光刺激；午后避免咖啡、浓茶和酒精；白天适度运动，但避免睡前 3 小时剧烈运动；卧室保持安静、黑暗和适宜温度。

## 需要警惕的情况

失眠持续超过 3 个月、严重影响白天功能，或伴随情绪持续低落、焦虑、明显体重变化，建议前往神经内科或心理门诊评估。睡眠中打鼾伴呼吸暂停、白天不可抑制地嗜睡，需要排查睡眠呼吸暂停。

## 就医边界

不建议长期自行服用安眠类药物，具体是否需要药物、用哪种、用多久应由医生评估。若出现自伤念头、意识异常或极度兴奋少眠，应及时线下就医。
